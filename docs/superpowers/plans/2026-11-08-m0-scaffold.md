# M0 Scaffold Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A deployable Vite/React/TypeScript app that renders a VRM avatar in a react-three-fiber scene with orbit controls and downloads a PNG of it, with lint, unit tests, end-to-end tests and CI in place.

**Architecture:** The app is a static single-page app with no backend. `AvatarParams` (zod schema) is the only state the UI touches; a zustand store holds it plus the avatar load status. The R3F `Viewer` loads the VRM through `@pixiv/three-vrm`, publishes its renderer/scene/camera through a small handle module, and the export module re-renders the scene at export size and captures the canvas to a PNG blob. WebGL is exercised only in Playwright (headless Chromium with SwiftShader); Vitest covers the pure logic and React components in jsdom.

**Tech Stack:** Node 20+, npm, Vite, React 19, TypeScript strict, `three` ≥0.167, `@react-three/fiber` 9, `@react-three/drei` 10, `@pixiv/three-vrm` 3, `zustand` 5, `zod` 3, Vitest + `@testing-library/react` + jsdom, Playwright (`@playwright/test`) + `pngjs`, ESLint 9 flat config + typescript-eslint + Prettier, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-08-dressup-game-design.md` — this plan implements milestone **M0** of §16: "Vite/React/TS, R3F scene, load a raw VRoid export, orbit, PNG export, CI with lint and tests. Done when a VRM renders and a PNG downloads."

## Global Constraints

- TypeScript `strict: true`; ESLint and `tsc --noEmit` pass in CI (spec §4, §16 M0).
- No backend, no network calls at runtime other than fetching the app's own static assets (spec §4).
- Pixel ratio capped at 2 for on-screen rendering (spec §14).
- PNG export renders at 2× the canvas CSS size, capped at 2048 px on the long edge (spec §10).
- All user-facing copy lives in `src/ui/strings.ts` (spec §11).
- Orbit controls: rotate and zoom only, pan disabled (spec §9).
- Spec §15 budgets to watch (not asserted by tests in M0): JS < 600 KB gzipped; base avatar < 3 MB. Record the `vite build` gzip size in the Task 6 commit message.
- The VRM used in M0 is a development placeholder; the real base comes from VRoid Studio in M1 (spec §7). Its source and licence are recorded in `assets/LICENSES.md` (spec §12).

## Review Focus

1. Browser without WebGL2 → a readable message, not a blank page (spec §14). Test added to Task 4 (`supportsWebGL2` unit test; `App` renders `strings.webglUnsupported`).
2. The VRM file fails to load (404, corrupt) → an error message, never an endless spinner (spec §14 "load fails"). Test added to Task 4 (Playwright: route the `.vrm` request to 404, expect `data-status="error"`).
3. Export clicked before the avatar is ready → button disabled, no blank PNG. Test added to Task 5 (`ExportButton` is disabled unless status is `ready`).
4. Very large or HiDPI viewports → export capped at 2048 long edge and sized from CSS pixels, not device pixels (spec §10, §14). Tests added to Task 5 (`computeExportSize` units; Playwright with `deviceScaleFactor: 2` asserts PNG dimensions).
5. Window resize → the canvas follows its container without distortion. Test added to Task 4 (Playwright resizes the viewport and asserts canvas size).

- [ ] **Step 3: Implement the export module and button**

- `computeExportSize`: `w = cssWidth*scale, h = cssHeight*scale`; if `max(w,h) > maxLongEdge`, multiply both by `maxLongEdge / max(w,h)`; return `Math.round` of each.
- `renderPng`: remember `gl.getSize(new Vector2())`, `gl.getPixelRatio()`, and `camera.aspect` if it is a `PerspectiveCamera`. Set `gl.setPixelRatio(1)`, `gl.setSize(size.width, size.height, false)`, camera aspect `width/height` + `updateProjectionMatrix()`, `gl.render(scene, camera)`, then **synchronously in the same tick** call `gl.domElement.toBlob(resolve, 'image/png')` inside a `new Promise`. In `finally`, restore pixel ratio, size (`updateStyle` false) and camera aspect, and render once more. Reject if `toBlob` yields `null`.
- `downloadBlob`: create an object URL, click a temporary `<a download={filename}>`, revoke the URL on the next tick.
- `ExportButton`: reads `avatarStatus` from the store; on click, `const h = getViewerHandle(); if (!h) return;` size from `h.gl.domElement.clientWidth/clientHeight` → `renderPng` → `downloadBlob(blob, 'avatar.png')`; disable the button while exporting. Position via a wrapper in `App` (`position: absolute; top: 12px; right: 12px`).

test('downloads a PNG at 2x CSS size, independent of device pixel ratio', async ({ browser }) => {
  const ctx = await browser.newContext({ viewport: { width: 800, height: 600 }, deviceScaleFactor: 2 });
  const page = await ctx.newPage();
  await page.goto('/');
  await expect(page.getByTestId('viewer')).toHaveAttribute('data-status', 'ready', { timeout: 45_000 });
  const canvas = page.getByTestId('viewer').locator('canvas');
  const css = await canvas.boundingBox();
  const [download] = await Promise.all([page.waitForEvent('download'), page.getByTestId('export-button').click()]);
  expect(download.suggestedFilename()).toBe('avatar.png');
  const buf = fs.readFileSync(await download.path());
  expect(buf.subarray(0, 8)).toEqual(Buffer.from([0x89, 0x50, 0x4e, 0x47, 0x0d, 0x0a, 0x1a, 0x0a]));
  const expected = computeExportSize(css!.width, css!.height);
  expect(readPngSize(buf)).toEqual(expected);
  expect(countDistinctColors(buf)).toBeGreaterThan(50);
  await ctx.close();
});
